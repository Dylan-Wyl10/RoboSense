# result/toynet/sumolog_pr2old

Raw SUMO output for this case set is **not tracked in git**.

16 files (140.2 MB) of `summary*.xml` / `tripinfo*.xml` were removed from tracking;
the aggregated `overall*.xml` files in this directory are still tracked and hold the
per-run metrics used in the paper.

See [`DATA.md`](../../../DATA.md) at the repository root for the full manifest and
for how to regenerate or restore the raw files.
